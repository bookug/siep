# Revisiting Equivalent Vertices of Subgraph Matching

implementation of state-of-the-art subgraph matching algorithms,
including techniques of equivalent trechniques, i.e., TurboISO andBoostISO.

---


# Algorithms

Seven subgraph matching algorithms: QuickSI, GraphQL, TurboISO, CFL-Match, VF3, CECI, DAF.

Each algorithm also has a boosted version, which is enhanced by techniques of BoostISO.
